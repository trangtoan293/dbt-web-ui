# Support

This project is maintained on a best-effort basis.

## Where to ask

- Use GitHub Discussions for setup questions, ideas, and usage help when
  Discussions is enabled.
- Use the bug report template for reproducible defects.
- Use the feature request template for scoped proposals.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; never disclose a
  suspected secret or exploit in a public issue.

Before opening a thread, search existing issues and include the commit SHA,
operating system, Docker/Compose versions, browser, relevant logs with secrets
redacted, and a minimal reproduction.

Maintainers do not provide an SLA, private implementation support, or emergency
operations assistance through the issue tracker.
